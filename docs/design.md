# 墨决 · 设计记录

## 一句话
水墨风的滑动拼刀对决（触屏优先）。你的每一刀都是一笔墨。

## 已定
- 玩法参考《无尽之剑》式一对一对决：滑动出刀、迎着来刀划即格挡、闪避。不做《武士2》式走关砍杂兵。
- 画风：宣纸白 + 浓墨黑，**朱砂红只用于“危险”**（敌人起手、来刀轨迹、你受伤）。
- 人物：已批准使用生成参考图 A（`gpt-image-2.5-sunburst`）→ Tripo 贴图 + Mixamo 骨骼 GLB 作为默认玩家外观；程序关节点 + IK 继续驱动真实骨骼、武器与战斗。敌人保留原几何体角色，`?character=code` 可对比/回退旧玩家。来源、导出统计与校准见 `character-asset.md`。笔触、墨溅、背景山水仍全部程序绘制；音效全部合成。
- 技术：Vite + Three.js；`tools/shot.mjs` 自动截图，`?auto` 自动对打测试。

## 第一阶段（2026-11-14）
- 过肩视角：镜头在主角右肩后，主角在左下前景，敌人在中右；两人共用同一套程序人物（主角发髻浅衣，敌人斗笠深衣）。
- 衣纹（交领右衽、衣襟、下摆、袖口）画在身体表面的贴图里，跟着身体扭转；不再用贴在外面的零件。
- 持剑姿势按剑尖朝前重做；剑尖朝下时手臂伸直。动作加惯性弹簧（手快、身体沉）、双脚落地迈步、出刀上步。
- 单手剑，没有盾。攻、挡、闪，再加归鞘 / 出鞘：
  - **逆时针画圈 = 归鞘**（约 0.55 秒，期间不能格挡）。归鞘后屏幕四周聚墨。
  - 归鞘中迎着来刀划 = **出鞘斩**：刀落前 0.24 秒内有效，无敌穿过来刀，造成 5 伤害并让敌人硬直。
  - 出得早 = 普通一刀，并且空门打开；被砍中会被打出归鞘状态。
  - 你归鞘时敌人会多等一会儿，并更常用假动作。
- 来刀方向固定为屏幕上的三种笔势：左上劈 135°、正劈 90°、右上劈 45°，红色刀弧画在交锋处；格挡容差 38°。

## 检验标准（第一阶段）
- 自己愿意反复打。
- 找 3–5 个朋友，不解释直接玩：三刀之内领会格挡；打完还想再打。

## 规则（第一场对决）
- 敌人护挡：剑护左 / 右 / 上，砍护住的一边会被挡（连挡两次他会反击），砍空门有伤害但他会立刻护住或反击。
- 敌人出刀三种方向：左上劈、右上劈、正上劈。起手时刀泛红、屏幕上画出红色刀路。
- 格挡：迎着刀来的方向划（左上劈 → 往左上划，正劈 → 往上划）。在刀落下前 0.36 秒内有效，0.12 秒内为完美格挡。
- 格挡成功敌人破防（完美 1.3 秒，普通 0.8 秒），此时每一刀都能砍中并累计连斩。
- 闪避：A / D 或两侧按钮，刀落前 0.42 秒内按下即可躲开，敌人收刀时有短暂空门。
- 后半血（势变）：起手更快、会连砍、会假动作换方向。

## 开发参数
- `?skip` 跳过标题直接开打；`?auto` 自动完美格挡；`?auto=none` 不格挡；`?auto=dodge` 只闪避；`?auto=draw` 破防就归鞘、出鞘。
- `?pose=windupL&ppose=parryL` 定格敌人 / 主角姿势（主角出刀：`cutw:0.7,-0.7`，w/i/f = 起手 / 命中 / 收势）。
- `?demo=draw` 开局即归鞘；`?cam=x,y,z&look=x,y,z` 试镜头。`tools/ppsheet.sh` 批量截主角姿势。
