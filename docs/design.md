# 墨决 · 设计记录

## 一句话
水墨风的滑动拼刀对决（触屏优先）。你的每一刀都是一笔墨。

## 已定
- 玩法参考《无尽之剑》式一对一对决：滑动出刀、迎着来刀划即格挡、闪避。不做《武士2》式走关砍杂兵。
- 画风：宣纸白 + 浓墨黑，**朱砂红只用于“危险”**（敌人起手、来刀轨迹、你受伤）。
- 纯代码：3D 人物由几何体拼成、关节点 + IK 摆姿势；笔触、墨溅、背景山水全部程序绘制；音效全部合成。
- 技术：Vite + Three.js；`tools/shot.mjs` 自动截图，`?auto` 自动对打测试。

## 规则（第一场对决）
- 敌人护挡：剑护左 / 右 / 上，砍护住的一边会被挡（连挡两次他会反击），砍空门有伤害但他会立刻护住或反击。
- 敌人出刀三种方向：左上劈、右上劈、正上劈。起手时刀泛红、屏幕上画出红色刀路。
- 格挡：迎着刀来的方向划（左上劈 → 往左上划，正劈 → 往上划）。在刀落下前 0.36 秒内有效，0.12 秒内为完美格挡。
- 格挡成功敌人破防（完美 1.3 秒，普通 0.8 秒），此时每一刀都能砍中并累计连斩。
- 闪避：A / D 或两侧按钮，刀落前 0.42 秒内按下即可躲开，敌人收刀时有短暂空门。
- 后半血（势变）：起手更快、会连砍、会假动作换方向。

## 开发参数
- `?skip` 跳过标题直接开打；`?auto` 自动完美格挡；`?auto=none` 不格挡；`?auto=dodge` 只闪避；`?pose=windupL` 定格某个姿势。
